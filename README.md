# Arifa Rowshon Fabeha — Portfolio

This React/Vite portfolio uses an editorial black-and-amber design for Arifa's confirmed details. It opens directly on the hero section and includes project overviews, coding profiles, an interactive coding quiz, a downloadable CV, and contact options.

## Run in Replit

Import this folder or the supplied ZIP into a Node.js Repl. Run `npm install`, then press Run or execute `npm run dev`. The app uses port 3000. Run `npm run build` to produce `dist/`.

## Publish on GitHub Pages

This repository's Pages site serves the `main` branch root. After changing the website, run `npm run build` and commit the generated root `index.html`, `assets/`, `cv.pdf`, `favicon.svg`, and `logos/` along with the source changes. The source HTML is `index.dev.html`; Vite serves it at `/` during development. The build uses relative URLs so the site also works at `https://husainxdev.github.io/arifa-rowshon-fabeha-portfolio/`.

## Update details

Edit `src/data/portfolioData.js` to add confirmed project technologies, screenshots, GitHub/live links, activity dates and certificates, and contact details. Empty fields are omitted. Quiz questions and explanations live in `src/data/quizQuestions.js`. The contact form opens a prefilled draft in the visitor's email app until `VITE_FORMSPREE_ENDPOINT` is set to a real Formspree endpoint in `.env`. See [CONTENT-TODO.md](CONTENT-TODO.md) for the remaining real content.

The CV is generated by `python3 scripts/generate-cv.py` (requires ReportLab). When confirmed personal details change, update the CV script and regenerate `public/cv.pdf` before building.

Project and activity fields without confirmed content are kept in the data file for future updates and stay hidden on the website.

## Animation controls

The site respects the device's reduced-motion setting. Decorative scenes pause outside the viewport, and the canvas pauses when the browser tab is hidden.

`MotionContext.jsx` coordinates motion preferences. Reusable heading reveals, pointer spotlights, card tilt, and the reading-progress line live in `components/ui/MotionPrimitives.jsx`. CSS keyframes are in `src/index.css`. Pointer tilt runs only with a mouse and a fine pointer.

## Project stories

- `ProjectShowcase.jsx` shows Shastho Sahayak and CloudSphere and opens keyboard-accessible project overviews. Add each verified screenshot as `{ src, alt, caption }` in `portfolioData.js`. Project documents and references use `{ label, url }`; diagrams use `{ src, alt, caption }`.
- Each project's `contribution` has `role`, `work`, `decisions`, and `lessons`. Fill these with Arifa's actual role and experience. Empty contribution fields stay hidden. List only confirmed implemented work under `features`.
